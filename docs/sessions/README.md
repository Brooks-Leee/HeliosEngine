# Session Logs — 每日协作日志

每天一个文件：`YYYY-MM-DD.md`，放在本目录（如 `2026-07-12.md`）。

## 规则
1. **只追加，不覆盖**：当天文件若已存在，直接在末尾添加你自己的块，绝不改写或删除别人的内容。
2. **每块带身份头**：`## HH:MM — [来源:名字] — 主题`，例如 `[agent:Claude]`、`[agent:Codex]`、`[human:你]`、`[human:Alice]`，便于追溯与区分不同 agent / 人的贡献。
3. **块内三段式**：`完成` / `卡点` / `下一步`（可增删）。
4. 开局先读本目录（看今天和最近的记录）再动手；会话结束追加你自己的块。
5. 当前整体焦点见 `../CLAUDE.md` 的 `Current Status` 段。

完整规范见 `../CLAUDE.md` 的 "Session logging convention" 段。
